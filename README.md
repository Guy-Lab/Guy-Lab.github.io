# Calculateur de combustion — Guy-Lab

Ce dépôt contient une page interactive pour composer un mélange de gaz et effectuer un bilan de combustion simplifié.

Fichiers importants

- `GMA026090711.html` — page interactive (exécutable depuis le web ou téléchargeable)
- `index.html` — page d'accueil et liens
- `assets/js/app.js` — logique JS (calculs simplifiés)
- `assets/css/style.css` — styles

Licence

Le contenu est publié sous CC0 (domaine public). Voir `LICENSE`.

Usage

- Ouvrir https://guy-lab.github.io/GMA026090711.html pour exécuter l'outil dans votre navigateur.
- Vous pouvez également télécharger le fichier HTML pour l'exécuter localement.

Remarque

Les calculs fournis sont indicatifs et simplifiés. Pour un usage industriel, vérifiez les données thermochimiques et méthodes de calcul.
